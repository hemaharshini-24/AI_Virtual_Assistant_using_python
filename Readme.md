# AI Virtual Assistant using Python

## Overview

This project is an AI-powered Virtual Assistant developed using Python and Machine Learning.

## Features

- Greetings
- Date & Time
- Weather Updates
- Calculator
- Open Websites
- Motivation Quotes
- Jokes
- Reminder Management
- Knowledge Base
- Chat History

## Technologies Used

- Python
- Scikit-learn
- Pandas
- JSON
- Google Colab
- TF-IDF Vectorizer
- Logistic Regression
- Requests API

## Model

- TF-IDF Vectorization
- Logistic Regression
- Accuracy: 78.67%
